Empiecen así

Necesitan Node.js 18.2 o superior, Git y un navegador. No hay nada que instalar: el proyecto no tiene dependencias.

git clone https://github.com/SU-USUARIO/equipo-N-api.git
cd equipo-N-api
npm run dev     # servidor y app en http://localhost:3000
npm test        # las pruebas del laboratorio

Al principio la aplicación dice «No existe /v1/evaluaciones»: la API todavía no existe. Ese es el trabajo del laboratorio.
